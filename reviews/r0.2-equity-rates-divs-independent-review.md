# R0.2 Equity Settlement Rate and Dividend-Yield Authority Independent Review

Slice: family A rates/dividends — when `market is not None`,
`EquityFuturePosition` and `EuropeanOptionPosition` require
`market.rates[<settlement ccy>]` (USD today via `getattr` currency default)
and `market.dividend_yields[symbol]`; missing keys raise
`MissingMarketDataError`. `market is None` still uses trade-local marks.
Workspace: uncommitted work on `r0-core-remediation` vs HEAD.
Implementer report: `reviews/r0.2-equity-rates-divs-report.md`.
Production code was not modified by this review.

## Verdict: REQUEST CHANGES

The two pricers do fail closed on a supplied snapshot that omits the USD
rate or the symbol dividend yield, and they still price from trade-local
`risk_free_rate` / `dividend_yield` when `market is None`. I verified that
in source and at runtime, including an in-memory `.get` restore. QuantLib
consumes the overlayed r/q, not the original trade marks.

That is not enough to approve the slice. Brief §8 requires existing
attribution, stress, hierarchy, API, and demo regressions to stay green
for the affected family. They do not. `_DEMO_AGGREGATE_MARKETS` for
`global-macro` and `equity-vol` still omit `dividend_yields`. Those
snapshots are the default market for `StressEngine`,
`ScenarioAttributionEngine`, `ReverseStressEngine`,
`MultiFactorReverseStressEngine`, `AttributionEngine` when no provider is
injected, and `PortfolioService.demo_attribution`. I priced SAMPLE
`fut-es` against the aggregate snapshot and got
`MissingMarketDataError: dividend_yields[SPY]`. The implementer listed
this class of breakage as a non-blocking fixture follow-up. It is a
required-regression failure, not out of scope.

## Attack results

1. **Named `.get` restore.** Missing-key tests fail (do not raise). Authority inequality tests still pass. The new raise cases are the contract lock.
2. **`rates={}` vs omitted `rates=`.** Distinct. `MarketSnapshot.rates` defaults to `{"USD": 0.04}`. Empty map raises `rates[USD]`; omitted `rates=` prices the AUTH future at 51007.533…. New tests pass `rates={}` and do not confuse the two.
3. **QuantLib overlay.** Consumes copied r/q. Not a leftover trade-mark price.
4. **`_equity_settlement_currency` / USD default.** Current equity types have no `currency` field; lookup is USD. EUR-only rates raise `rates[USD]`, which is fail-closed under today’s USD assumption. This does not hide a missing-currency error because there is no contractual currency yet. Brief §1 still asked to add that field; documented limitation, not a silent fallback.
5. **Other equity future/option snapshot tests.** Real failures. Not out of scope.
6. **Duplicate helpers.** Same deferred Minor as prior R0.2 slices; now three more copied pairs.
7. **TDD red narrative.** Ignored as proof. Runtime probes and pytest are the evidence.

## Findings

### 1. VALID — Important — Caller migration omitted DemoAggregate and family-A fixtures

- Files: `backend/app/sample.py` (`_DEMO_AGGREGATE_MARKETS`),
  `backend/app/risk/stress.py`,
  `backend/app/risk/scenario_attribution.py`,
  `backend/app/risk/reverse_stress.py`,
  `backend/app/risk/reverse_stress_multi.py`,
  `backend/app/risk/attribution.py` (default provider),
  `backend/app/services/portfolio_service.py` (`demo_attribution`),
  `backend/tests/test_attribution.py`,
  `backend/tests/test_full_reval_golden.py`,
  `backend/tests/test_var_methodology.py`,
  `backend/tests/test_component_var.py`,
  `backend/tests/test_scenario_attribution.py`,
  `backend/tests/test_next_phase.py`,
  `backend/tests/test_reverse_stress.py`,
  `backend/tests/test_reverse_stress_multi.py`
- What's wrong: After this slice, a supplied snapshot is authoritative for
  equity-future/option carry. `dividend_yields` defaults to `{}`.
  `_DEMO_MARKETS["global-macro"]` already seeds
  `{"NVDA": 0.0, "SPY": 0.0}` and prices SAMPLE `fut-es`.
  `_DEMO_AGGREGATE_MARKETS["global-macro"]` and `["equity-vol"]` do not.
  Several engines still resolve that aggregate snapshot by default.
  Hand-built option markets in attribution / full-reval / VaR methodology /
  component-VaR tests also omit the symbol yield.
- Why it matters: This is fail-closed, not a silent wrong PV. It still
  breaks the family-A production demo path and the regressions the brief
  listed as handoff gates. Probed: aggregate SAMPLE future raises
  `dividend_yields[SPY]`; production demo snapshot prices. Live
  `POST /risk/attribution/demo` raises the same error (unhandled 500).
  `VaRAnalytics` / `demo_market_snapshot` still work, so summary/VaR and
  stress/attribution now disagree on whether SAMPLE is even valuable.
- Suggested fix: Seed `dividend_yields` on both aggregate demo snapshots
  (same NVDA/SPY zeros as `_DEMO_MARKETS`), and on every existing
  future/option `MarketSnapshot` that is passed into `value` /
  full reval / attribution / VaR. Then rerun the suites above. Do not
  defer that as a later fixture pass.

### 2. VALID — Minor — Required rate/div helpers are duplicated

- Files: `backend/app/pricing/builtin.py`, `backend/app/pricing/quantlib.py`
- What's wrong: Identical `_equity_settlement_currency`,
  `_required_settlement_rate`, and `_required_dividend_yield` now sit
  next to the already-duplicated `_required_equity_spot`. Prior R0.2
  reviews deferred the spot helper.
- Why it matters: A later family slice can tighten one copy (trade id,
  shared lookup, curve vs scalar) and leave the other on the old
  contract. Not a current behavior bug — both raise the same
  `factor_key` today.
- Suggested fix: One shared helper next to `MissingMarketDataError`.

### 3. VALID — Minor — `MissingMarketDataError` still names only the factor key

- File: `backend/app/market/demo_snapshot.py` (unchanged this slice)
- What's wrong: Brief §3 asked the typed error to name trade id **and**
  factor key. Call sites still pass only `rates[USD]` /
  `dividend_yields[<symbol>]`.
- Why it matters: Same shape as approved R0.2-A / spots / vol. Logs for
  a multi-name book will not say which trade failed. Not a silent
  fallback.
- Suggested fix: Thread `position.id` into the error when the helpers
  are unified.

## Items checked and not findings

- Builtin and QuantLib no longer call
  `rates.get("USD", position.risk_free_rate)` or read
  `position.dividend_yield` when `market is not None`.
- QuantLib copies onto a local `model_copy`; the caller position is not
  mutated. Overlay raises before the session if the key is absent.
- `market.rates` / `market.dividend_yields` are mapping proxies; `[]`
  still raises `KeyError` and is translated. Present `0.0` is a valid
  yield, not missing.
- `LegacyDemoPricingAdapter` / `DemoSampleMarksSnapshotAdapter` already
  seed equity-future/option `risk_free_rate` into `rates["USD"]` and
  `dividend_yield` into `dividend_yields[symbol]`. `market is None`
  and adapter-built ad-hoc books still price.
- `_DEMO_MARKETS` (used by `demo_market_snapshot` / VaR / ES / summary)
  already has NVDA/SPY yields. `test_es_contributions.py`,
  `test_marginal_var.py`, `test_demo_portfolios.py`, and
  `test_sensitivities.py` (option path is `market is None`) stayed green.
- `MarketSnapshot.rates` default `{"USD": 0.04}` means omitting `rates=`
  is not a missing-USD-rate case. Tests isolate with `rates={}`.
  Pre-existing schema; not introduced here.
- `_equity_settlement_currency` defaults to USD. No hidden
  missing-currency success on current models. Adding a contractual
  `currency` field remains a brief leftover, same class as prior
  deferred domain work.
- FX / bond / swap / IR `.get` fallbacks were not removed.
- I saw `ConflictingSampleMarkError` on
  `test_hierarchy.py::test_sample_portfolio_hierarchy_still_drills_to_trade`
  (subset → demo adapter) and on some `test_next_phase` API logs. That
  is the R0.2-A identity/adapter path, not this slice’s r/q helpers. Not
  scored here.
