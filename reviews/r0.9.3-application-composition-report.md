# R0.9.3 — Explicit application composition

## Task
RF-010 / R0.9.3 — construct `PortfolioService` in FastAPI lifespan

## Owner
Backend / API Engineer

## Summary
`PortfolioService` is no longer assigned at `app.api.deps` import time.
Lifespan calls `build_portfolio_service()`, stores the instance on
`app.state.portfolio_service`, and constructs `RiskRunWorker` with that same
object. `get_portfolio_service(request)` reads `app.state` like
`get_risk_run_worker`. `app.main.service` is a thin `__getattr__` alias to the
lifespan instance (or the TestClient-without-lifespan factory fallback). No DI
container. Risk numbers unchanged.

**Disposition: CLOSED** — the four RF-010 acceptance cells are MET. Named
residual: dual-use `AttributionRequest` / `RiskChangeAttributionRequest` /
`WhatIfRequest` remain in domain. Independent review pending.

TDD: module-global `portfolio_service = build_portfolio_service()` failed first;
`get_portfolio_service` lacked `request`; `app.state.portfolio_service` was
missing until lifespan composition.
