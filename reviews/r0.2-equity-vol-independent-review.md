`vol_surfaces[symbol]` quote or `equity_vols[symbol]` when a snapshot is
supplied (brief §2 family A; rates/dividends deferred).

what-if snapshot slice that was not re-reviewed.

## Verdict: APPROVE

Both pricers fail closed on a supplied snapshot that has spot but no
usable AUTH surface and no `equity_vols[AUTH]`. Surface-only snapshots
price without a scalar map. `equity_vols[AUTH]` prices and does not
mutate the trade. `market=None` still reads `position.volatility`. I
verified that in source and at runtime, including a call-site
monkeypatch of the old `.get` fallback. Remaining residuals are helper
edge cases, weak isolation in the new AUTH-book tests, and coverage /
error-shape leftovers — not open Critical/Important production defects
on this vol-only slice.

## Findings

### 1. VALID — Minor — “Usable” surface is any non-None payload

- File: `backend/app/pricing/surface_vol.py` (`required_equity_option_vol`)
- What's wrong: The helper docstring says surface vol if usable, else
  `equity_vols[name]`, else `MissingMarketDataError`. The code treats
  any `vol_surfaces[name] is not None` with `spot > 0` as usable and
  then calls `option_vol_from_snapshot(..., fallback=0.0)`. An empty
  payload `{}` raises `KeyError: 'asset_class'` from
  `vol_surface_from_dict` and never falls through to a present scalar.
  The `0.0` fallback is dead under today’s paired guards; if those
  guards ever diverge it would price at zero vol.
- Why it matters: Brief §8 allows richer-snapshot → simpler-snapshot
  fallback. A snapshot with a broken surface **and** `equity_vols[AUTH]`
  should still price. No current fixture or adapter writes an empty
  surface, so this is not a live production path.
- Suggested fix: Treat interpolate-failure as “not usable” (fall
  through to `equity_vols[name]`, then typed missing). Do not pass
  `fallback=0.0`; interpolate the grid directly.

### 2. VALID — Minor — New vol tests reuse the deep-ITM spot fixture

- File: `backend/tests/test_market_authority.py`
  (`_option_book`, success / surface / `market=None` cases)
- What's wrong: AUTH is `spot=999`, `strike=100`. Vega is ~zero.
  `test_equity_option_uses_trade_local_vol_when_market_is_none` passes
  because 0.40 vs 0.20 differs by 5.5e-7. The `equity_vols` and
  surface-only success cases compare snapshot spot 101 + vol 0.40 to
  no-market spot 999 + vol 0.20, so a mutation that ignores vol (or
  ignores the surface and uses trade vol) still satisfies
  `valuation != local`.
- Why it matters: Acc 5’s missing-key cases are the real lock, and I
  confirmed they fail a `.get` restore. Existing
  `test_builtin_equity_option_pv_differs_on_skewed_surface` already
  isolates surface vs scalar at the same spot. The new tests overclaim
  “PV change / surface preference” in the implementer report.
- Suggested fix: Hold spot fixed (101 vs 101, or ATM 100/100) when
  asserting vol authority; keep the deep-ITM book for spot tests only.

### 3. VALID — Minor — `MissingMarketDataError` still names only the factor key

- File: `backend/app/market/demo_snapshot.py` (unchanged this slice)
- What's wrong: Brief §3 asked the typed error to name trade id **and**
  factor key. Call sites still pass only `equity_vols[<symbol>]`.
- Why it matters: Same shape as approved cash-equity and future/option
  spot slices. Not a silent fallback.
- Suggested fix: Thread `position.id` when the next equity-family slice
  touches the helper.

### 4. VALID — Minor — QuantLib surface path now precomputes a point sigma; the existing forbid-test misses it

- Files: `backend/app/pricing/quantlib.py` (overlay),
  `backend/tests/test_quantlib_pricing.py`
  (`_forbid_point_vol_lookup`)
- What's wrong: Overlay always calls `required_equity_option_vol` →
  `option_vol_from_snapshot` (probed: 1 call on surface-only) before
  `_black_vol_handle` builds the QL grid. NPV still comes from the
  grid: flat surface-only matched `equity_vols=0.40` exactly
  (182.009…). `test_quantlib_equity_option_uses_surface_term_structure_not_point_sigma`
  still patches `quantlib.option_vol_from_snapshot` with
  `raising=False` — an attribute this module has never imported — so
  the test stays green. New market-authority surface-only coverage is
  Builtin-only. LINEAR / cache missing-vol cases are also Builtin
  `value()` / probed, not suite-locked.
- Why it matters: For a well-formed equity surface the numbers do not
  change. The extra interpolate can fail closed on a garbage payload
  before QL would have skipped it (`raw or None` + `asset_class`
  check) and used the scalar. The documented “must not precompute a
  point sigma” invariant is no longer what the test measures.
- Suggested fix: Overlay should require a surface **or** scalar
  without interpolating a point when a grid will be attached. Point
  the forbid-test at `app.pricing.surface_vol.option_vol_from_snapshot`
  or at `required_equity_option_vol`. Add a QuantLib surface-only
  authority case if that path stays first-class.

request forbids treating those leftovers as Important on this slice.
