# R0.6.6 Contribution reuse

## Task

R0.6.6 — Avoid whole-book full revaluation once per factor family.

## Owner

Portfolio Risk Engineer.

## Summary

Full-reval factor contributions no longer apply family-only shocks and reprice the book per family × observation. ES `_aggregate_factor_pnl_full_reval` / panel variant reuse the joint trade/scenario P&L already computed for portfolio ES and attribute families from one base Δ-Γ Greek valuation. Scenario attribution does the same from the single shocked snapshot plus those base Greeks. `interaction` = joint full-reval − sum(families) so contributions still reconcile. RF-007 remains `IN PROGRESS`.

## What Was Reused

- Joint full-reval position P&L series (`VaRAnalytics._position_pnls` / stress `by_trade_pnl`).
- One base `PricingEngine.value` (or `value_portfolio`) for additive Greeks.
- Existing LINEAR / Δ-Γ family split (`_aggregate_factor_pnl_linear`, `_aggregate_factor_pnl_from_panel`, `_panel_linear_contribution`) with shock-unit helpers.

## What Is No Longer Done

- Extra `apply_market_scenario` / `apply_scenario` per factor family (or per `RiskFactor.key`) on the contribution path.
- Extra whole-book `value` / `value_portfolio` per family × observation.

## Call-count bound

| Path | Extra family work | Not |
|---|---|---|
| ES FULL_REVAL four-macro / panel | O(N) base valuations for Greeks | O(N×S×F) isolated books |
| Scenario attribution `decompose` | 0 extra applies; base valuations already required for trade P&L | O(F) isolated applies × N values |

Joint full-reval of the book once per observation/scenario remains O(N×S). That is the remaining RF-007 pricing loop, not family-multiplied contribution work.

Remaining isolation revals on this path: **none**. Nonlinear / cross-factor remainder stays in `interaction` rather than a second snapshot stack.

## Numerical conventions

- Units: unchanged (currency P&L; vega per vol point; DV01 per bp; equity/FX relative return).
- Sign: loss = −P&L; ES non-negative; stress P&L negative = loss.
- Tolerances: cash-equity FULL vs LINEAR family P&L abs `1e-12`; contribution reconcile abs `1e-6` / rel `1e-8` (existing suites).
- Portfolio FULL_REVALUATION VaR/ES is unchanged (still joint reval). Factor *bucket* amounts on nonlinear books can differ from the old isolated-reval split; the residual restores reconcile.

## Tests

Added `backend/tests/test_contribution_reuse.py`:

- Family helpers do not `apply` or `value` per family.
- ES FULL report `value` calls stay O(N×S), not O(N×S×F).
- Cash-equity FULL factor series / ES match LINEAR (existing units, not invented goldens).
- Scenario attribution applies the full scenario once; no isolated-factor applies; existing key/reconcile pins.

## RF-007 Status

RF-007 remains `IN PROGRESS`. This slice removes family-multiplied extra full books on the contribution path. It does not close N×S joint pricing, process partitioning (R0.6.5), or N=100/1k benches.
