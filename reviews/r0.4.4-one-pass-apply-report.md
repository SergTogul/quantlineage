## Task

## Owner
Market Data & Curves Engineer

## Summary
Rewrote `MarketSnapshot.apply` to stage all nested map fields once (mutable
plain dicts), apply each `(RiskFactor, amount)` with the same semantics as
historical per-factor `bump` (equity/FX relative; vol relative + surface rules;
RateZero parallel vs tenor), then construct **one** new immutable snapshot via
a single `model_copy` / nested freeze. `bump` remains the single-factor public
API and delegates to `apply([(factor, amount)])`. Id policy: chain the same
`:bump:…` suffixes as successive `bump` calls so `apply(shocks).id` matches
sequential bump’s final id (callers such as `apply_scenario` may still
`model_copy` a scenario id afterward). Mark parity pinned exactly vs sequential
`bump`; structural monkeypatch proves multi-factor `apply` is O(1) in
`model_copy` / `_apply_nested_freeze`, not O(K). RF-006 and RF-004 stay
**IN PROGRESS** (not closed).
