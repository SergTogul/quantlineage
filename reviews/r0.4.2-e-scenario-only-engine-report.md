# R0.4.2-E — Engine-facing Scenario-only (dual-model collapse)

Status: **COMPLETE pending review** (2026-09-09)  
Owner: Stress & Scenario Engineer  
Related: RF-011 (**IN PROGRESS**, do not CLOSE), milestone § R0.4.2

## Goal

Stop engine-facing stress / attribution / threat from branching on
`Scenario | StressScenario`. Canonical apply is typed `Scenario` /
`FactorShock`. Legacy `StressScenario` remains HTTP/wire adapter only
(deprecated POST routes + DI libraries), with bp↔decimal conversion only
via `shock_units`.

## What changed

- Added `to_canonical_scenario` / `to_canonical_scenarios` in
  `scenario_model` (identity for `Scenario`; `scenario_from_stress` for
  legacy).
- `StressEngine.run` / `evaluate` / `contributions` and
  `ScenarioComparisonEngine.compare` convert once at the public boundary,
  then apply / evaluate fields on `Scenario` only.
  `_evaluation_fields` no longer branches on `StressScenario`.
- Attribution `_to_formal` delegates to `to_canonical_scenario`;
  position P&L apply is typed `Scenario`.
- HTTP: deprecated `/stress/custom`, `/evaluate/custom`, `/compare` and
  DI-backed `/stress` / `/evaluate` adapt via `stresses_to_scenarios`
  before `PortfolioService`. Formal `/formal/*` paths unchanged
  (`wires_to_scenarios`). Routes **not** deleted.
- Shock units unchanged: rate bp↔decimal only in
  `_expand_stress_to_shocks` / `scenario_to_stress`.

## Explicitly unchanged

- Deprecated StressScenario POST route **behavior** (still functional).
- `DEFAULT_SCENARIOS` / `THREAT_SCENARIOS` still *defined* as
  `StressScenario` (adapted at the boundary; needs a market to expand).
- Persistence scenario-definition storage still StressScenario-shaped.
- Historical `MarketScenario` and reverse-stress factor-family solvers.
- Demo snapshot ids.
- Numerical identity vs goldens / `content_hash` / P&L.

## RF-011 disposition

**IN PROGRESS — do not CLOSE.**

Required-direction cells still open:

- Explicit equity-currency/rate selection is still implicit USD default
  (`MarketSnapshot.rates` default `{"USD": 0.04}`).
- Historical / reverse / persistence do not all *store* canonical
  `Scenario`.
- Dual type remains as the HTTP/library adapter (intentional this slice).
