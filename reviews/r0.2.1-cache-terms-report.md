## Summary
`trade_cache_key` now hashes contractual economics from
`terms_from_position`, not a parallel deny-list of mark field names.
Unknown families still raise `TypeError` (from `terms_from_position`).
Positions that differ only in live marks still share a key; strike,
notional, maturity, quantity, and `fixed_rate` still change it.

Equity-family `InstrumentTerms` add settlement `currency="USD"` that
`*Position` DTOs never hashed. That field is dropped at hash time so the
v1 payload matches the prior deny-list economics identity. No schema
version bump (`equity_terms_v1` / `equity_option_terms_v1` / … unchanged).
`value()` is not rewired. Compatibility `*Position` DTOs still carry marks.
RF-001 remains open.
