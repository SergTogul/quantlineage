## Accepted residuals (not MET)

1. **Object ACLs / ownership / IDOR** — shared token is all-or-nothing. RF-013 leftover “object ACLs = RF-014” stays true as a residual, not a local-demo UNMET.
2. **TLS / reverse-proxy** — not in repo.
3. **Secret management** — env token; Compose `quantlineage`/`quantlineage` DB password.
4. **HTTP enqueue queue depth** — `POST /risk/runs` does not reject overload. Worker batch ≠ enqueue cap.
5. **`docker run -p 8000:8000` without `QUANTLINEAGE_SHARED_DEPLOYMENT=1`** — in-container `uvicorn --host 0.0.0.0` is not a host publish; operators who publish beyond loopback must set the shared flag + token (`BUILD_NOTES.md`). Default Compose does not do this.
6. **Deferred minors** (not KEEP OPEN): `is_public_path` `..` prefix (R0.11.5 Minor); dual-book per-list position sum (R0.11.3 Finding 4); `MarketSnapshot.model_copy` finite re-check (R0.11.2 Finding 4); RiskRun `request` blob stringifies NaN (R0.11.2 Minor).

Do **not** start OIDC, object ACLs, TLS, or a secret manager from this close.
