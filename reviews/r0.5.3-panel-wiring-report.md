## Numerical conventions
- Units: match `historical_data.py` / `FactorObservationSeries` /
  `HistoricalFactorPanel`
  - equity / FX: relative return (`0.01` = +1%)
  - vol: relative change of vol level; vega contribution uses ×100 (per vol point)
  - rate: panel stores **basis points** (`1.0` = +1bp); `panel_amount_to_bump`
    converts to decimal (`/ 10000`) before `MarketSnapshot.bump`
- Sign convention: same as historical series (positive = up move); loss = −P&L
- Day count/calendar if relevant: n/a
- Tolerances/reference: exact / `1e-12` on constructed fixtures; LINEAR P&L
  is `delta_i * r_i` (equities) and `dv01_i * bps_i` (tenors). Full-reval
  equity identity: qty=10, spot=100, AAA +10% / BBB −20% → P&L = −100.
  VaR goldens re-run unchanged (no file edit).
