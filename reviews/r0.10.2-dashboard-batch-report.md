## Summary
Added one coherent dashboard batch: `POST /risk/dashboard` (dual-mounted at `/api/v1/risk/dashboard`) returns the existing UI keys `{portfolio, summary, stress, threats, contributors, limits, factors, varReport, hierarchy, attribution}` from a single HTTP request. `PortfolioService.dashboard()` calls the existing methods sequentially (same market-required semantics; no shared snapshot refactor). `loadDashboard()` now calls that path only — no `Promise.all` of nine POSTs. The client still does not compute risk numbers. Classified HEAVY because the batch includes hierarchy / VaR / evaluate. Not a RiskRun job platform; work still runs on the request thread.
