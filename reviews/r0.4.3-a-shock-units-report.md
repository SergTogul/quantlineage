  - `relative_vol_move_to_vol_points(vol_pct: float | np.ndarray)`

## Numerical conventions
- Units:
  - Rates for snapshot bump: absolute decimal (`0.0001` = +1 bp); historical /
    SensitivityEngine bump sizes in bp convert via `bps_to_decimal_rate`.
  - Historical `vol_pct` / `vol_moves`: relative vol move; ×100 → vol points
    for vega P&L via `relative_vol_move_to_vol_points`.
  - SensitivityEngine FD vega bumps remain absolute decimal vol
    (`0.01` = +1 vol point); not converted to relative.
- Sign convention: unchanged (helpers are scale-only).
- Day count/calendar if relevant: n/a
- Tolerances/reference: existing approx P&L / sensitivity goldens unchanged
  (`abs=1e-12` / FD tolerances as before).
