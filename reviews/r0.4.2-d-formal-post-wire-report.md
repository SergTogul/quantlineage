# R0.4.2-D — Formal ScenarioWire as primary stress POST + UI

Status: **COMPLETE pending review** (2026-09-09)  
Owner: Frontend/Risk UX + Stress & Scenario / Backend (contract moves together)  
Related: RF-004 (**CLOSED**), RF-011 (stays IN PROGRESS), milestone § R0.4.2

## Goal

Make formal `ScenarioWire` the primary client POST path for custom stress /
threat evaluate / hedge compare, and stop the live UI from calling legacy
`StressScenario` bodies.

## What changed

### Backend

- Added `POST /risk/stress/formal/compare` (`FormalScenarioComparisonRequest` →
  `wires_to_scenarios` → `PortfolioService.compare_scenarios`).
- Marked legacy `POST /stress/custom`, `/evaluate/custom`, `/compare` as
  **deprecated** (OpenAPI `deprecated=True` + description pointing at formal
  twins). Routes still work for back-compat.
- Registered formal compare as HEAVY + methodology-bearing in
  `execution_class.py`; OpenAPI critical-path / typed-response lists updated.
- Backpressure refuse coverage for formal compare when external worker is on.

### Frontend

- `scenarioPayload(form, portfolio?)` now emits formal `ScenarioWire`
  (`category`, `shocks[]`) with display `%` → fraction and rates bp → absolute
  decimal (`/ 10_000`). Family shocks expand onto portfolio-derived factor keys
  (demo global-macro fallback when portfolio absent) for legacy scalar parity.
- `evaluateCustomScenario` → `POST /api/v1/risk/stress/formal/evaluate/custom`.
- `compareHedge` / `defaultHedgeScenarios` → formal wire +
  `POST /api/v1/risk/stress/formal/compare`.
- Scenario Builder copy + payload preview updated; MSW handlers retargeted.

### Findings / milestone

- RF-004 **CLOSED** — acceptance evidence (unit goldens, shock_units,
  snapshot-aware paths, formal wire as primary UI path) met; dual-POST residual
  is deprecated back-compat only.
- RF-011 remains **IN PROGRESS** — typed nesting + dual domain models /
  deprecated StressScenario POST residual.

## Explicitly unchanged

- Domain `StressScenario` / `ScenarioLike` engine support.
- Legacy StressScenario POST route **behavior** (still functional).
- Reverse-stress routes (still family-factor wire, not ScenarioWire).
- RiskRun / hierarchy / RF-015 HEAVY gate policy (formal compare only added to
  the same HEAVY map as legacy compare).

## Parity

- Backend: UI-style formal evaluate (expanded shocks) matches legacy scalar
  evaluate P&L; formal compare matches legacy compare scenario P&L / VaR
  improvement.
- Frontend tests assert formal wire shape and formal MSW URLs.
