# R0.4.2-F — Canonical Scenario in libraries + persistence

Status: **COMPLETE pending review** (2026-09-09)  
Owner: Stress & Scenario Engineer  
Related: RF-011 (**IN PROGRESS**, do not CLOSE), milestone § R0.4.2

## Goal

Stop DEFAULT/THREAT in-code libraries and `ScenarioDefinitionRepository` from
*storing* `StressScenario`. Engine already applies canonical `Scenario`
(R0.4.2-E). Broadcast macros (`equity_shock=-0.10`) still expand at apply
time against the live `MarketSnapshot` — same pattern as
`crisis_library.CrisisDefinition` + `crisis_scenarios(base)`. Demo equity
names are not frozen at import.

## What changed

- Added `BroadcastShockTemplate` / `BroadcastScenarioDefinition` and
  `expand_broadcast_definition`. `to_canonical_scenario` expands templates
  against the live snapshot (rate bp→decimal only via `shock_units`).
- `DEFAULT_SCENARIOS` / `HYPOTHETICAL_THREAT_SCENARIOS` / `THREAT_SCENARIOS`
  are templates, not `StressScenario`. Crisis rows use `crisis_as_broadcast`.
  `default_scenarios(base)` / `threat_scenarios(base)` materialize `Scenario`.
- Memory + SQLAlchemy `ScenarioDefinitionRepository` save/get/`list_all`
  take/return `Scenario` and persist ScenarioWire JSON.
- `default_seed_scenarios()` expands templates against the demo snapshot
  and seeds canonical `Scenario`.
- HTTP DI (`get_default_stress_scenarios` / `get_baseline_stress_scenarios`)
  returns `list[Scenario]`. Deprecated StressScenario POST routes still
  convert once at the route.

## Explicitly unchanged

- Deprecated StressScenario HTTP POST routes (adapters only).
- Historical `MarketScenario` and reverse-stress factor-family solvers.
- Demo snapshot ids (`position_marks`).
- Numerical identity vs goldens / `content_hash` / P&L.
- Nested MarketSnapshot Pydantic rewrite; RF-012 ladders; RF-013 versioning.

## RF-011 disposition

**IN PROGRESS — do not CLOSE.**

Required-direction cells still open:

- Historical replay still stores/uses `MarketScenario`, not canonical
  `Scenario`.
- Reverse-stress solvers still operate on factor-family shocks, not a
  stored `Scenario`.
- Deprecated StressScenario POST routes remain (intentional adapter).
