## Leftover object-pack holes (native Historical path)

These are leftovers, not a flip to REQUEST CHANGES.

1. **No object `pnl()` pack on the production native Historical branch.** `_pnl_via_scenario_kernel` does not build `Exposure` / `Shock` and does not call `kernel.pnl` when `pnl_from_arrays` is callable. `HistoricalRiskEngine.calculate` (LINEAR / Δ-Γ) goes through `approximate_pnl_series` → that helper. Env `native` loads `NativeScenarioKernel`, which has the method.
2. **Python reference kernel still packs object `pnl()`.** Claimed. User-allowed. Not the native leftover.
3. **`NativeScenarioKernel.pnl()` still object-packs** (`eflat` / `sflat` list comps + `(ctypes.c_double * n)(*…)`). Historical no longer calls it on the arrays branch. Direct `pnl()` callers (kernel ABI tests, benches) still do. That is the documented object API, not this leftover.
4. **Default `RISKFORGE_SCENARIO_KERNEL=python` never enters the kernel.** NumPy formula only. This is why RF-017 must stay open: native Historical is wired and tested, but it is opt-in, not the production default.
5. **Duck-type fallback:** a `ScenarioKernel` without callable `pnl_from_arrays` still object-packs. Production `get_scenario_kernel("native")` returns `NativeScenarioKernel`. A hand-rolled wrapper that only implements `pnl()` would still pack objects.
6. **Historical still copies four 1-D factor vectors into a new `(n, 4)` C-contiguous buffer** (and five scalars into `(1, 5)`). That is an array layout pack, not an Exposure/Shock object pack. Inputs are not a pre-packed shock matrix. `_native_f64_c_buffer` then passes those buffers by pointer.
7. **Post-pack shape check is effectively unreachable.** `np.empty` of those shapes cannot fail the `(1, 5)` / `(n, 4)` assert unless strides constants disagree. Fail-closed for bad *caller* shapes is `_require_aligned_1d_factors` (and NumPy column assign).
8. **Spy locks `approximate_pnl_series`, not `HistoricalRiskEngine.calculate`.** The engine uses the same helper. Engine-level native parity is numeric only (`test_historical_engine_native_var_matches_python`), not a method-name spy.
9. **1×S Historical still goes through the existing serial-below-4096 C++ gate.** Out of scope. Not an object-pack hole.
