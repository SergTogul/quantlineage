# R0.2-A Implementation Report

## Status

DONE locally. No commit or push was created.

## Summary

- Added a validated legacy sample-mark adapter that collects candidates before
  constructing a `MarketSnapshot`, accepts exact duplicates, and raises
  `ConflictingSampleMarkError` for unequal duplicates independent of order.
- Made `PositionMarketDataProvider` a deprecated, conflict-raising wrapper.
- Added explicit demo snapshots, including tenor-aware USD rate snapshots and
  deliberate aggregate compatibility snapshots for unchanged stress and
  attribution goldens.
- Routed LINEAR, DELTA_GAMMA, and FULL_REVALUATION VaR/ES calculations through
  one explicit base snapshot and made `PortfolioService` resolve that snapshot
  for summary, VaR, and ES.
- Documented the production pricing contract, added
  `LegacyDemoPricingAdapter`, and required explicit snapshot identity in the
  valuation cache. Equity-family cache keys now exclude embedded observable
  marks while retaining contractual economics.
- Preserved the committed deterministic demo artifact byte-for-byte.

## Compatibility choice

Used the first allowed option: demo portfolios have explicit snapshot factories,
and the default sample-mark adapter/provider raises on conflicts. There is no
`legacy_last_writer_wins` flag. Pre-R0.2 stress/attribution numerical goldens use
explicitly declared aggregate demo snapshots; they are not constructed by
iteration-order overwrite.

### Changes

- Equity cash spot is required when `market is not None`: missing
  `equity_spots[symbol]` raises `MissingMarketDataError` from
  `BuiltinPricingEngine` and the QuantLib overlay. `market is None` still
  uses trade-local marks. Bond/swap/FX/IR fallbacks were not removed.
- Demo matcher binds a canned snapshot only when `portfolio.id` is a known
  demo **and** the position-id set equals that demo's set. Subset/superset
  and diverged books fall through to `DemoSampleMarksSnapshotAdapter`.
- `PortfolioService.contributors` and `compare_var_methodologies` pass
  `self.market_snapshot(portfolio)` the same way as `var_report`.
