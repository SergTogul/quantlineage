## Summary
Production historical VaR, VaR report, and ES contribution entry points no longer
infer a `MarketSnapshot` from the book when `market` is omitted. They raise
`ValueError("production risk calculation requires an explicit MarketSnapshot")`
via `require_explicit_market` and do not call `demo_market_snapshot`.
`full_revaluation_pnl_series` already required an explicit base snapshot.

`demo_market_snapshot` remains for named demo/sample helpers and tests that opt
in. Empty ES books still return zero contributions, but only after an explicit
snapshot is supplied. Signatures stay `market: MarketSnapshot | None = None` so
the failure is a domain `ValueError` (same type and “explicit MarketSnapshot”
wording as the production cache), not a `TypeError`. FX pricing fallbacks and
`as_of` typing were not changed.

TDD: `tests/test_omit_market.py` failed first (`DID NOT RAISE ValueError`) while
engines still inferred demo marks. After fail-closed, those tests passed and
callers/tests that omitted `market=` were updated to pass fixtures or
`demo_market_snapshot` in tests only.
