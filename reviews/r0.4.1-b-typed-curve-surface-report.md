## Summary
Canonical views now reconstruct typed nesting over unchanged flat snapshot
storage: `VolMarket.surfaces` is `Mapping[str, VolSurface]` via
`vol_surface_from_dict`; `RateMarket.curves` exposes named `YieldCurve`
(`from_zero_dict` when all key tenors are present, otherwise equivalent
nodes). Invalid *present* surface/curve payloads fail closed
(`ValueError`/`KeyError`/`TypeError`) instead of skipping to `{}`.
`MarketSnapshot.fx_spots` and `FxMarket` reject non-6-letter ISO pair keys
via `_require_fx_pair`. Empty `vol_surfaces` / `curves` / `fx_spots` remain
valid. Scalar `discount` / `projection` / `spreads` / `key_rates` identity
unchanged. RF-011 remains **IN PROGRESS** (dual `StressScenario`/`Scenario`
collapse out of scope).
