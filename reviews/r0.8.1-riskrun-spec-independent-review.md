## Strengths

- Fields are first-class, not comments: domain attributes, ORM `mapped_column`s, mapping copy, Alembic `003`, and equality tests.
- `as_of` is optional (`None` for pre-spec rows) and shares the fail-closed snapshot union. Labels are not rewritten to wall-clock.
- `calculation_config` is a closed knob set (`observations`, `seed`, `confidence`), not a free-form blob.
- Memory `set_status` switched to `model_copy`, which is the change that actually keeps spec fields across lifecycle transitions. SQLAlchemy already updated the row in place and remapped via `row_to_risk_run`.
- Old-row path is nullable end to end. A real `002` database with a `risk_runs` row upgrades to `003` without rewrite.
- Enqueue/API omission is explicit. This slice does not pretend RF-009 is closed.
