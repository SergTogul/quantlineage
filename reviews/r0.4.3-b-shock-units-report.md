## Public/interface changes
- **Breaking (rates reverse-stress wire):** `from_wire_bound("rates", 500)` now
  returns `500.0` (search magnitude), not `0.5`. Callers that meant 500 bp
  must pass `max_shock=0.5` (`to_wire_shock` → 500 bp). Default `0.80` unchanged.
- No DTO / OpenAPI schema change; default examples already use `0.80`.

## Numerical conventions
- Units:
  - Relative vol move / absolute decimal vol delta → vol points via
    `relative_vol_move_to_vol_points` (×100 scale; attribution uses absolute
    vol level delta with the same scale).
  - Rates reverse-stress: search magnitude × `RATES_BP_SCALE` bp →
    `bps_to_decimal_rate` for `FactorShock` decimal zeros.
  - Attribution DV01 path: decimal rate delta → `decimal_rate_to_bps`.
- Sign convention: unchanged.
- Day count/calendar if relevant: n/a
- Tolerances/reference: existing goldens / reverse-stress tolerances unchanged
  for the ≤1 legacy rates path.
