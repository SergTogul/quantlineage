## Task
Remaining interactive HEAVY UI POSTs fall back to RiskRun when the inline gate refuses

## Status

## Summary
All live risk-terminal HEAVY POSTs in `frontend/src/api.js` now prefer the sync route and, on HTTP 400 with `details.use === "/risk/runs"`, enqueue a typed RiskRun and poll until COMPLETED/FAILED. Shared helpers `postHeavyOrRiskRun` / `runViaRiskRun` (same pattern as `loadDashboard`) avoid duplicated poll loops. Gate-off behavior is unchanged (sync POST only).

Backend adds ten `run_type` values with R0.8.4 request schemas so custom evaluate / reverse / compare / attribution / ES / VaR-compare / query payloads are not forced through the canned `stress` / `summary` types. INTERACTIVE routes (`/limits/drilldown`, scenario GETs, LINEAR summary, `/factors`) stay sync.
