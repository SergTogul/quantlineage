## Owner
Market Data & Curves Engineer (Quant Pricing lookup in Builtin / QuantLib)

## Summary
Equity cash, equity-future, and European-option Position DTOs now carry an
explicit `currency` field (default `"USD"` so existing demo books stay valid).
`_equity_currency` copies that field onto `InstrumentTerms`; production
Builtin/QuantLib valuation looks up `market.rates[terms.currency]`. A EUR
option or future on an explicit snapshot with `rates={}` or USD-only rates
fails closed (`MissingMarketDataError rates[EUR]`), instead of silently using
the snapshot constructor default USD 0.04. P&L for EUR options moves when the
EUR rate changes and is unchanged when only USD moves. Cash equity still
values from spot only. Attribution `_rate_currency` uses the same explicit
field for equity derivatives.

RF-011 remains **IN PROGRESS** (Task 13 residuals: StressScenario libraries /
persistence; historical `MarketScenario`; reverse-stress factor families).

## Public/interface changes
- Equity / equity-future / European-option Positions accept `currency`
  (default `"USD"`). Omitted currency on wire still USD.
- Missing settlement rate for the instrument currency raises
  `MissingMarketDataError` (`rates[CCY]`).
- `MarketSnapshot.rates` default `{"USD": 0.04}` when omitted is unchanged.

## Numerical conventions
- Units: unchanged (scalar `market.rates[ccy]` for equity carry / option r)
- Sign convention: unchanged
- Day count/calendar if relevant: existing option/future conventions
- Tolerances/reference: EUR vs USD isolation `rel=1e-12` / `abs=1e-12`; no
  formula edits for USD books that already had matching snapshot rates
