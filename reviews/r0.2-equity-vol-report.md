# Agent Handoff Template

## Task
R0.2 equity-family option vol authority

## Owner
Quant Pricing Engineer

## Summary
When a `MarketSnapshot` is supplied, `EuropeanOptionPosition` now requires a
usable vol surface quote or `market.equity_vols[symbol]` in both
`BuiltinPricingEngine` and the QuantLib overlay. A missing key raises
`MissingMarketDataError` with `factor_key="equity_vols[<symbol>]"`. Existing
`option_vol_from_snapshot` is preferred when a surface quote is present; the
scalar map is required only when that path has nothing. Trade-local
`position.volatility` remains only when `market is None`. Spot authority from
the prior slice is unchanged. Rates and dividend-yield `.get` fallbacks are
unchanged. FX, bond, swap, and IR fallbacks were not removed.

## Public/interface changes
- No DTO, API, or snapshot schema change.
- Production pricing contract for European equity options: a supplied snapshot
  must contain a usable `vol_surfaces[symbol]` quote or `equity_vols[symbol]`,
  or valuation raises `MissingMarketDataError`.
- `required_equity_option_vol` is a new shared helper next to
  `option_vol_from_snapshot`. It does not accept a trade-mark fallback.

## Numerical conventions
- Units: option PV remains Black–Scholes unit price times `quantity`; vega
  remains per 1 vol point.
- Sign convention: unchanged (long call positive in rising spot / rising vol).
- Day count/calendar if relevant: unchanged; this slice is vol authority only.
- Tolerances/reference: authority tests assert inequality versus trade-local
  marks, unchanged `model_dump`, and `pytest.approx` only where the no-market
  path is compared to itself via a richer trade-local vol. No new golden PV.

## Known limitations / risks
- USD rates and dividend yields still fall back to trade-local marks when a
  snapshot is supplied but those keys are absent (next micro-slice).
- Other instrument families (FX, bond, swap, IR) still use `.get` / trade-mark
  fallbacks, including FX option vol.
- `market is None` still prices from embedded marks (compatibility path).
- Equity instruments still assume USD for the rate lookup key.
- `MarketSnapshot.rates` still defaults to `{"USD": 0.04}`, so a snapshot that
  omits an explicit USD rate is not the same as trade-local `risk_free_rate`.
