## Attack results

1. **`report` / `calculate` still does `market if market is not None else demo_market_snapshot(portfolio)`.** Gone from `historical.py`, `var.py`, and `es.py`. Replaced by `require_explicit_market(market)`. ES moved that check above the empty-book return, so an empty book can no longer skip the snapshot.
2. **`market=None` default remains and still prices (no raise).** Default remains (`MarketSnapshot | None = None`) so the failure is a domain `ValueError`, not a `TypeError`. It does **not** price. Probe: `calculate(..., market=None)` and `report(..., market=None)` raise.
3. **Tests only hit a wrapper; production classes still infer.** Not found. New tests call the three production classes. Wrappers (`compare_methodologies`, `incremental_var`) that still accept `market=None` now raise when they reach `calculate` — they do not infer.
4. **Goldens weakened or skip when market omitted.** Not found. See criterion 8. Goldens now pass an explicit unit snapshot so they keep running after fail-closed; they do not skip.
5. **RF-001 marked CLOSED.** Not found.
6. **Callers still invoke production report without a snapshot and the test suite now hides that (silent default elsewhere).** Not found on the claimed path. `PortfolioService` summary / `var_report` / `es_contributions` / contributors already resolve one snapshot and pass it. `compare_methodologies` and `incremental_var` omit-`market=` now raise (probed). Updated caller tests pass fixtures or `demo_market_snapshot` explicitly; they do not install a silent production default in `var.py` / `historical.py` / `es.py`.
