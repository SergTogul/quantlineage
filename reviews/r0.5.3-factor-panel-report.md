four MVP aggregate columns. One observation can hold `EquitySpot("AAA")`,

## Numerical conventions
- Units: match `historical_data.py` / `FactorObservationSeries`
  - equity / FX: relative return (`0.01` = +1%)
  - vol: relative change of vol level
  - rate: basis points (`1.0` = +1bp) — **not** `FactorShock` decimal-rate units
- Sign convention: same as historical series (positive = up move)
- Day count/calendar if relevant: n/a (panel is dated observations only)
- Tolerances/reference: exact float equality on constructed fixtures; VaR
  goldens and demo arrays re-run unchanged
