## Summary
Added a frozen `TradeCalculationArtifact` keyed by a stable non-empty `trade_id`. A
risk run can now *represent* reusable per-trade results: PV, the hierarchy-additive
Greeks (`delta`, `gamma`, `vega`, `dv01`, `fx_delta`), stress P&L by scenario id,
and an optional historical P&L vector.

Construction is `from_parts(...)` or `from_valuation(Valuation)` (`position_id` →
`trade_id`, `market_value` → `pv`). No `hierarchy` import. Artifacts add: PV and
listed Greeks sum; `stress_pnl` merges by scenario id; `historical_pnl` adds
elementwise when both present and the same length, and fails closed on length
mismatch or present-vs-omitted.

Invariants: finite numbers only; empty / whitespace `trade_id` rejected; stress
keys must be non-empty; `historical_pnl` is omitted as `None` — an empty
sequence is rejected, not stored.

**Hierarchy still full-reprices per node.** This slice is the type only. RF-008
is **not** closed.
