## Findings

### 1. VALID — Minor — Contract tests accept comments and do not pin cwd / m9

- Files: `backend/tests/test_pr_fast_ci.py`
- What's wrong: Predicates are unanchored substrings on the raw job block.
  In-memory probes that left the suite green:
  - `name: backend-subset` plus `# name: PR-FAST` (Acc 1 display name gone)
  - `if: false` (job exists, never runs)
  - frontend `working-directory` omitted or set to `backend`
  - golden paths commented out; pytest pointed at `tests/test_unrelated.py`
  - `run: npm install` with `# run: npm ci`
  - drop `tests/test_m9_risk_properties.py` (`REQUIRED_BACKEND_TESTS` omits it)
- Why it matters: These tests are the only lock that a “PR-FAST” check still
  means the listed commands ran. Acc 6’s exact mutations (delete job, delete
  filename strings) do fail. The hunt’s comment-only name and a wrong npm cwd
  do not. `test_m9_risk_properties.py` is in the job (Acc 2 “high-value
  properties”) but is not pinned.
- Suggested fix: Parse the job (or require `name: PR-FAST` as a 4-space key,
  not a comment). Assert frontend npm steps have `working-directory: frontend`
  and that each golden path appears on a non-comment `pytest` argument line.
  Add `tests/test_m9_risk_properties.py` to `REQUIRED_BACKEND_TESTS`. Optional:
  reject `if:` on `pr-fast`.
