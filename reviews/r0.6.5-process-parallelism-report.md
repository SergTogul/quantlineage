## What Is The Process Partition

| Path | Behavior |
|---|---|
| Compose `backend` + `RISKFORGE_EXTERNAL_WORKER=1` | HTTP enqueues; API process does not execute full reval |
| Compose `worker` / `python -m app.worker` | Separate OS process claims and executes RiskRuns |
| Extra worker replicas | `FOR UPDATE SKIP LOCKED` claim; one QuantLib address space per process |
| In-process `RiskRunWorker` `ThreadPoolExecutor` | Job scheduler only; pricing still takes `_QL_PROCESS_LOCK` |
| `full_revaluation_pnl_series` | Sequential; no thread/process pool |
