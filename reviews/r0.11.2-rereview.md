## Finding 1 — original vs now

Live formal routes are dual-mounted at `/risk/stress/formal/...` and
`/api/v1/risk/stress/formal/...` (`APIRouter(prefix="/risk")`). There is no
`/api/v1/stress/formal/...` mount; those paths 404. The original 500s were on
the `/risk/...` formal routes.

| Body | Original | Now (canonical + legacy dual-mount) |
|---|---|---|
| `amount: Infinity` / `NaN` / `-Infinity` on `/formal/custom` | **500** `internal_error` | **422** `validation_error` |
| `amount: Infinity` on `/formal/evaluate/custom` | **500** | **422** |
| `max_loss_pct: Infinity` | **500** (wire accepted; adapter `FiniteFloat`) | **422** at request validation |
| `max_loss_pct: NaN` | **500** (`json.dumps(errors, allow_nan=False)`) | **422**, `input` is the label `"NaN"` |

All 24 live-route probes (2 mounts × 2 paths × 2 fields × 3 tokens) were 422.
`json.dumps(body, allow_nan=False)` succeeded. Envelope keys were exactly
`{code, message, details}`. `details.errors[].input` was `"NaN"` /
`"Infinity"` / `"-Infinity"`, type `finite_number`.

Domain construction, previously **accept**:

| Construct | Original | Now |
|---|---|---|
| `FactorShockWire(amount=nan/inf/-inf)` | accept | **REJECT**, JSON-safe `errors()` |
| `ScenarioWire(max_loss_pct=inf)` | accept (`Field(gt=0)`) | **REJECT** |
| `FormalCustomStressRequest.model_validate(..., amount=inf)` | accept | **REJECT** |
| `FormalCustomStressRequest.model_validate(..., max_loss_pct=nan/inf)` | accept / 422-then-500 | **REJECT** |

Signed finite `amount=-0.10` and `max_loss_pct=0.05` still construct.
`max_loss_pct=0` still fails `gt=0`. A valid formal custom POST still returns 200.
