### 4. Root snapshot vs additive VaR/ES

Hierarchy additivity in this codebase is MV / Greeks / stress P&L (`abs` 1e-9). VaR/ES are computed on each node subset and are **not** summed. SAMPLE tree after this change: additive invariants hold (probe, 0 failures). Strategy-level `var_99` child-sum is ~2.3× parent — that is existing non-additivity of VaR, not a new semantic.

`test_risk_at_matches_subset_var` / `test_greeks_var_es_stress_limits_on_nodes` use a 3-equity book and compare `risk_at` (now root-market) to `HistoricalRiskEngine.calculate(subset)` **without** `market=`. Default methodology is DELTA_GAMMA: synthetic factor panel + aggregate Greeks. Extra unused spots on the root snapshot do not change AAA-only Greeks, so those tests stay green while saying nothing about SAMPLE.

SAMPLE child **rate** nodes now price against explicit `demo:global-macro` (`key_rates` USD 5Y = 0.041, scalar `rates[USD]` = 0.04) rather than an adapter subset (bond `yield_rate` 0.041 only). That is the architecture-brief contract (one market state, not per-subset inference). Default DELTA_GAMMA child VaR moves only when those Greeks move. No SAMPLE child VaR golden exists. Not a defect; the suite would not catch a mistaken change that only affected mixed-USD child VaR.
