### Minor

#### 1. VALID — Minor — O(1) freeze/copy asserts lack a lower bound

`test_apply_freezes_once_not_per_factor` asserts `copy_calls["n"] <= 1`,
`freeze_calls["n"] <= 2`, and both `< k`. Those upper bounds correctly reject
an O(K) regression (probe: sequential path is 5/5). They also pass if
instrumentation never fires (`0, 0`). Actual counts under a working monkeypatch
are `1` / `1`.

- Suggested fix (later): assert `copy_calls["n"] == 1` and
  `1 <= freeze_calls["n"] <= 2` (or exact expected freeze count).

#### 2. VALID — Minor — Mark/id parity oracle shares staging via `bump` → `apply`

`_sequential_bump` calls `bump`, which delegates to `apply([(factor, amount)])`,
so the parity test compares multi-shock staging to N single-shock staging
passes through the same `_stage_shock` — not a frozen copy of pre-R0.4.4 bump
bodies. Still valuable for compounding / id-chain consistency; historical mark
semantics are covered by the mechanical diff plus existing single-factor bump
tests (spots, vols, surfaces, parallel/tenor rates).

- Suggested fix (later): optional golden marks for the multi-factor fixture, or
  a comment that the oracle is “N× one-factor apply,” not pre-slice bytecode.
