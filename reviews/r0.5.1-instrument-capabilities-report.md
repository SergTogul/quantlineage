## Summary
Added a static (non-plugin) registry of the ten production
`InstrumentTerms` / `trade_cache_key` families. Each row declares the
pricing adapter name strings (`quantlib` production, `builtin` reference —

## Public/interface changes
- New lookup: `get_capability(family: str) -> InstrumentCapability`.
- New types: `InstrumentCapability`, `PRODUCTION_FAMILIES`,
  `ADAPTER_QUANTLIB` (`"quantlib"`), `ADAPTER_BUILTIN` (`"builtin"`).
- No DTO, API, snapshot, or pricing-engine change.
- Required factor kinds reuse existing classes only: `EquitySpot`,
  `EquityVol`, `RateZero`, `FXSpot`, `FXVol`. There is no typed
  `DividendYield` or `IRVol`; those appear only as snapshot maps
  (`dividend_yields`, `ir_vols`).

Family rows (sensitivities = Valuation fields produced today):

| Family | Required kinds | Sensitivities | Snapshot maps (required ⊂ declared) |
|---|---|---|---|
| equity | EquitySpot | delta | equity_spots |
| equity_future | EquitySpot, RateZero | delta, dv01 | equity_spots, rates, dividend_yields |
| european_option | EquitySpot, EquityVol, RateZero | delta, gamma, vega | equity_spots, equity_vols, rates, dividend_yields, vol_surfaces |
| bond | RateZero | dv01 | rates, key_rates, curves |
| swap | RateZero | dv01 | rates, key_rates, curves |
| fx_forward | FXSpot, RateZero | fx_delta | fx_spots, rates |
| fx_option | FXSpot, FXVol, RateZero | fx_delta, gamma, vega | fx_spots, fx_vols, rates, vol_surfaces |
| ir_future | RateZero | dv01 | rates, projection_rates, key_rates, curves, ir_future_quotes |
| cap_floor | RateZero | vega, dv01 | rates, projection_rates, key_rates, curves, ir_vols, vol_surfaces |
| swaption | RateZero | vega, dv01 | rates, projection_rates, key_rates, curves, ir_vols, vol_surfaces |

FX option domestic/foreign rates are both `RateZero` via `rates[ccy]`
(pair `[-3:]` domestic, `[:3]` foreign). Equity option dividends are
`dividend_yields[symbol]`.
