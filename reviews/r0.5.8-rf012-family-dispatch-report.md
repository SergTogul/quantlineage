## Recommendation

**CLOSE.** Adding a production family is now one coherent adapter path plus tests:

1. domain terms (discriminated union — named residual)
2. one `InstrumentCapability` registry row
3. one overlay handler in `app.pricing.snapshot_overlay`
4. one Builtin `value()` handler
5. one QuantLib `value()` handler
6. tests

Not a second overlay copy. Not a second `isinstance` ladder in `factors.py` / `cache.py` / `historical.py`. If `value()` still isinstance-dispatched, this gate would KEEP OPEN.

Named residual (not blocking close): discriminated Position/Terms unions in `domain/` (the type, not a dispatch ladder).

## Why CLOSE (not KEEP OPEN)

`value()` no longer isinstance-dispatches. Overlay is not duplicated. A new family does not require a second overlay copy or a second isinstance ladder in factors/cache/historical.

Would this gate defend CLOSE to a second reviewer? **Yes**, provided the named residual stays written (domain unions).

## Residuals (accepted; not blocking close)

1. **Discriminated Position/Terms unions in `domain/`** — the type, not a dispatch ladder.
2. Per-family `_bond` / `_option` / overlay handler *implementations* remain (the ladder was the defect).
3. Not a plugin / entry-point loader (explicitly out of scope).
4. No typed `IRVol`; IR option vega stays on `Valuation`.
