# QuantLineage Wave B — Analytics & Visualization

Goal: make QuantLineage immediately understandable and visually polished without turning it into a retail-planning product.

Outcome:
- historical analytics
- benchmark comparison
- drawdown / rolling vol / VaR-ES views
- factor and concentration visuals
- KR-DV01 curve
- flagship T0→T1 risk-change waterfall
- polished 5–8 minute demo

Core rule: backend owns financial math; frontend only requests, formats, sorts, and charts deterministic backend results.

Order:
1. Architecture decisions
2. Historical analytics backend
3. Benchmark / relative risk
4. Risk visualizations
5. Risk-change waterfall
6. Historical Analytics UI
7. Demo/polish
8. Hostile review

Non-goals: retirement planning, cash-flow planning, robo-advice, tax optimization, efficient-frontier product expansion, or browser-side risk math.
