# Task 1 Stage 10.1 True Multi-Factor Historical Risk Panel

Replace the four-macro **demo** projection with deterministic per-factor history that is actually used in VaR.

## Goal

Distinct per-name/per-tenor history is used in VaR. Dataset→panel lineage is exact. No silent family-wide broadcast on the new dataset. Hierarchy root VaR reconciles with direct VaR. Existing exact VaR/ES goldens stay intact.

## Target factors (canonical RiskFactor types)

Must be present as independent columns:

- EquitySpot:AAPL
- EquitySpot:MSFT
- EquitySpot:NVDA
- EquityVol:AAPL
- EquityVol:MSFT
- EquityVol:NVDA
- RateZero:USD:2Y
- RateZero:USD:5Y
- RateZero:USD:10Y
- FXSpot:EURUSD
- FXVol:EURUSD

Also include EquitySpot:SPY and EquityVol:SPY if demo books still hold SPY (fail-closed missing-factor must not break existing books). Do not broadcast SPY onto AAPL/MSFT.

## Quant contract for this task

- Shock unit: EquitySpot / FXSpot relative return (`0.01` = +1%). EquityVol / FXVol relative vol-level change. RateZero basis points (`1.0` = +1bp).
- Sensitivity unit: unchanged engine conventions (delta × relative return; vega × vol points after relative→absolute conversion; DV01 × bp).
- Sign: positive equity/FX return raises the spot; positive rate bp raises the zero; positive vol move raises vol. Loss = −P&L. VaR/ES floored at 0.
- Currency/notional: position currency; FX pair EURUSD as existing FX adapters.
- Base market: the bound `MarketSnapshot` (demo `_DEMO_MARKETS` / explicit test snapshots). Positions are contractual economics only.
- Reconciliation: hierarchy root `var_99` equals direct `HistoricalRiskEngine` / `PortfolioService.summary` `var_99` on the same book, snapshot, dataset, methodology (abs 1e-12 on identical P&L or documented engine tolerance).
